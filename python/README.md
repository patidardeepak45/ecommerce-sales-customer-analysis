# Python Analysis

This folder contains Python-based analysis for the E-Commerce Sales & Customer Analysis project.

## Libraries
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL Connector (if connecting directly to MySQL)

## Analysis Tasks
- Calculate sales and customer KPIs.
- Analyze top-performing products and categories.
- Calculate average order value and repeat customer rate.
- Explore monthly revenue trends.
- Validate key metrics against MySQL results.

The notebook will document the analysis steps, code, and findings.
