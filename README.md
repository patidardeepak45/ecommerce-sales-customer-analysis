# E-Commerce Sales & Customer Analysis

## Project Overview
An end-to-end data analytics project analyzing e-commerce sales, product performance, customer behavior, order status, and revenue trends using **MySQL, Python, and Power BI**.

The goal is to transform raw data into meaningful business insights that support data-driven decision-making.

## Tools & Technologies
- **MySQL:** Data querying, joins, aggregations, and business analysis.
- **Python:** Pandas and NumPy for data analysis and KPI validation.
- **Power BI:** Interactive dashboards, data modeling, and DAX measures.

## Project Objectives
- Analyze completed sales and overall revenue.
- Identify top-performing products and categories.
- Understand customer purchasing behavior and repeat customers.
- Compare sales performance across cities and time periods.
- Analyze order status and payment methods.
- Build an interactive dashboard for business insights.

## Key Business Findings
- **Completed Revenue:** ₹4.67 crore
- **Completed Orders:** 661
- **Unique Customers with Completed Orders:** 234
- **Completed Quantity Sold:** 1,200
- **Average Order Value:** ₹71,359.21
- **Repeat Customers:** 188
- **Repeat Customer Rate:** 80.34%
