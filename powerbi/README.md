# Power BI Dashboard

This folder contains the Power BI dashboard for the E-Commerce Sales & Customer Analysis project.

## Dashboard Pages
1. Executive Overview
2. Product & Category Analysis
3. Customer & City Analysis
4. Order & Payment Analysis
5. Revenue & Sales Trends
6. Business Insights

## Key Features
- Interactive slicers and filters
- DAX measures for sales and customer KPIs
- Product and category performance analysis
- Customer behavior and repeat purchase analysis
- Monthly and quarterly revenue trends

The Power BI report is saved as a `.pbix` file and will be added to this folder.
